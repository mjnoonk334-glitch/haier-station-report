نظام ويب احترافي لإعداد وإدارة وطباعة تقارير عمليات محطة الحاير.

## 🚀 البدء السريع

### 1. الاستخدام المحلي (الفوري)
```
1. افتح ملف: haier_station_report.html
2. في متصفح (Chrome, Firefox, Safari, Edge)
3. ابدأ في ملء النموذج مباشرة!
```

### 2. الاستضافة على الإنترنت
اتبع التعليمات في ملف `HOSTING_GUIDE_AR.md`

## 📊 الحقول المدعومة

### البيانات العامة
- التاريخ
- الاستهلاك (MW/DAY)
- درجة الحرارة

### الإنتاج والتصدير
- السعة التشغيلية
- إنتاج الشميسي والمنفوحة
- الإنتاج الاحتياطي
- تصدير الشميسي والمنفوحة

### حالة الآبار
- آبار في الخدمة
- آبار خارج الخدمة
- ملاحظات

### جودة المياه
- درجة الحرارة (°C)
- العكورة (NTU)
- الكلور الحر (ppm)
- درجة الحموضة (pH)
- التوصيلية (µS/cm)
- الأملاح الذائبة (ppm)

### تقرير الصيانة
- جدول ديناميكي لإضافة/حذف صفوف
- المعدة والموقع والوصف

### التوقيع
- معد التقرير
- المشرف

## 🎯 الخطوات الأساسية

### إنشاء تقرير جديد:
1. اضغط "تقرير جديد" من القائمة اليسرى
2. ملء جميع الحقول المطلوبة
3. اضغط "حفظ التقرير" 💾

### عرض تقرير سابق:
1. اختره من قائمة التقارير اليسرى
2. سيتحمل محتوى التقرير تلقائياً

### طباعة:
1. اضغط "طباعة" 🖨️
2. سيظهر معاينة الطباعة
3. اختر الإعدادات وطباعة

### تصدير:
1. اضغط "تصدير JSON" 📥
2. سيُحمل ملف بصيغة JSON
3. شارك الملف مع الآخرين
